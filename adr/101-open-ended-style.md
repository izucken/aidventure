# Open-ended style

At no point in the project should it ever imply to be an engine or a device for nothing of the sort: a play, a script, a roleplay, a game, a book, an RPG.
Project MUST remain open-ended in terms of how the narratives and systems interact and are presented to either models and users.
Project NEVER forces models or users to write any specific kind of narrative structure, except that which the system can support in principle.
