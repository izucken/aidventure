# UX room

Let the user breathe. At all times UI MUST hold only what is important right then and there.
All extraneous materials, settings, and circumstantial actions must be kept aside and possibly even invisible unless hovered.
Notification boxes or errors are displayed somewhere on the side and never persist forever.
Keep the app layout relatively to a page-width - people find it hard to read lines of text at 1980px.
The layout constraint MUST be universal, so that the UI does not jump.
This means that all UI elements must be made with the limitation in mind.
