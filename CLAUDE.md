# aidventure

## ADR

`adr/` holds the project's directions: decisions that must always hold, each in
its own file. They are not history, they are constraints. Read every file in
`adr/` before doing anything, and check work against them before reporting it.

## Finding things

Explanations cascade (adr/5): the root README links to per-folder READMEs, and
each folder's README holds only what is relevant to that folder. Read the README
of the folder you work in. Do not add a detail to a README that a code comment
already carries.
